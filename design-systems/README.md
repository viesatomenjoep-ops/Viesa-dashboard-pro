# Design systems

Deze map bevat Markdown-bestanden die als **design-context** gelden voor het
Viesa Dashboard. Bestanden hier beschrijven de huisstijl, UI-patronen en
componentrichtlijnen. Raadpleeg deze bestanden vóór het bouwen of aanpassen van
UI, zodat het dashboard consistent blijft.

## Inhoud

- `huisstijl.md` — kleuren, typografie en visuele basisregels.
- `patronen.md` — layout- en componentpatronen (KPI's, tabellen, knoppen).
